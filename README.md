# HUAWEI-HCCDA-AI
This repositories contain 12 weeks learning material containing python, machine_learning, deep_learning, hugging_face etc.
Welcome to my 12 Weeks of AI & Machine Learning Learning Journey!

This repository contains 12 weeks of structured learning materials, practical exercises, Python programming, and hands-on projects covering the fundamentals of Artificial Intelligence (AI), Machine Learning (ML), Deep Learning (DL), and modern AI tools.

The goal of this repository is to build a strong foundation in AI and Machine Learning through consistent learning, coding, experimentation, and practical implementation.
